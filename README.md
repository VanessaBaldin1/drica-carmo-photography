# 📸 Drica Carmo Photography - Portfólio

Este é o site de portfólio profissional da **Drica Carmo Photography**.  
O projeto foi desenvolvido com foco em **estética minimalista**, **sofisticação** e **alta performance**, ideal para exibir fotografias de luxo, casamentos e ensaios Fine Art.

---

## ✨ Funcionalidades

- **Design Premium:** Estética voltada para o mercado de luxo com tipografia refinada.    
- **Portfólio Filtrável:** Galeria organizada por categorias (Casamentos, Ensaios, Eventos).  
- **Depoimentos Estilo Editorial:** Seção de feedback de clientes com layout estilo revista.  
- **Totalmente Responsivo:** Adaptado para smartphones, tablets e desktops.  
- **Botão Flutuante do WhatsApp:** Facilita o contato imediato para orçamentos.  
- **Animações de Scroll:** Elementos surgem suavemente conforme a navegação.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando **tecnologias web modernas** para garantir rapidez, performance e facilidade de manutenção:

- **HTML5:** Estrutura semântica e organizada.  
- **CSS3:** Design responsivo com CSS Variables, Grid e Flexbox.  
- **JavaScript (Vanilla):** Lógica de troca de tema, filtros e animações.  
- **Google Fonts:** Playfair Display (serifa) e Montserrat (sans-serif).  
- **Font Awesome:** Ícones sociais e de interface.
